About This Computer

retr-oq · Aqua · ~2001 (Cheetah / Puma)

An early OS X Aqua desktop for retr-oq: global menu bar, jelly traffic lights, genie minimize into the Dock, and a vertical pinstripe wash. The look is period Cupertino — translucent menubar, soft blue desktop, glass-ish Dock shelf — rebuilt as original art, not a screenshot of anyone's OS.

Window / menu / Dock behavior lives in shared/osx/ so a later Tiger or Leopard skin can reuse the same chrome APIs. This theme directory is mostly skin: CSS, icons, and thin wiring.

Art and sounds here are original (no Apple marks or sampled system assets). Font: TeX Gyre Heros from vendor/next/. See NOTES.md for the vendor-CSS search that led to hand-rolled chrome.
