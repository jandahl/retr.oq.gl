    About retr-oq

    This is a prototype Windows 95 desktop -- a taskbar with a real Start menu, and windows you can drag by the title bar and resize from any edge or corner, minimize down to a taskbar button, and maximize to fill the screen.

    No functional app lives inside a window yet -- that's deliberately left for a follow-up once the window manager itself is solid.

    My Computer

    Nothing to browse yet -- there's no real file system behind this window, just window-manager chrome (see issue #29's "not in scope" section).

    Recycle Bin

    The Recycle Bin is empty.

    Settings

    Only Display is wired up here -- the rest of a real Control Panel (Fonts, Mouse, Keyboard, and so on) isn't built.
